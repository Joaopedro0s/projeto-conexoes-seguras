# Módulo 4 — VPN (Virtual Private Network)

## Objetivo

Demonstração prática do funcionamento de uma **VPN**, abordando criação de túneis criptografados, encapsulamento de pacotes e proteção do tráfego em redes públicas.

## Conceito Técnico

Uma VPN cria um túnel cifrado entre cliente e servidor. Todo o tráfego é encapsulado e criptografado antes de sair pela rede pública, garantindo:

- **Confidencialidade**: dados ilegíveis para interceptadores externos.
- **Integridade**: pacotes não podem ser alterados sem detecção.
- **Autenticidade**: apenas partes autorizadas participam do túnel.
